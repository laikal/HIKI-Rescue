# HIKI Rescue Privacy Policy

**Last updated: September 21, 2026**

HIKI Rescue is a Windows recovery and diagnostic utility developed by **Eltax**.

## 1. Personal Information

HIKI Rescue does not collect, store on external servers, sell, or share personal information.

HIKI Rescue does not use:

- Telemetry
- Analytics
- Advertising
- Tracking technologies
- User accounts
- Cloud storage operated by HIKI Rescue
- Remote servers operated by HIKI Rescue

## 2. Local Processing

HIKI Rescue performs recovery, diagnostic, maintenance, and system repair operations locally on the user's Windows device.

Depending on the function selected by the user, HIKI Rescue may invoke Windows system utilities, components, or APIs related to features such as:

- System Restore
- DISM
- System File Checker (SFC)
- CHKDSK
- Windows Disk Cleanup
- Windows Memory Diagnostic
- Reliability Monitor
- System Information
- DNS cache flush
- Display configuration cache reset

These operations are initiated and processed locally on the user's device.

## 3. Local Logs and Backups

HIKI Rescue may create local diagnostic logs or backup files when needed for a recovery or diagnostic operation.

For example, the application may create registry backup files before modifying supported display configuration cache entries.

These files remain on the user's device and are not automatically transmitted to Eltax or to any server operated by HIKI Rescue.

The storage location may vary depending on the installation type and Windows packaging environment.

## 4. External Links

HIKI Rescue may open external websites only when the user explicitly selects a corresponding button or link.

These may include:

- The official HIKI Rescue GitHub repository
- The Hikimori Neko CHZZK channel

HIKI Rescue does not automatically send personal information to these websites.

Once an external website is opened, use of that website is governed by its own privacy policy and terms.

## 5. Microsoft Windows Components and Services

Some HIKI Rescue functions use utilities, APIs, and components provided by Microsoft Windows.

Any information processed directly by Windows or Microsoft services is subject to Microsoft's applicable privacy terms and policies and is outside the control of HIKI Rescue.

## 6. Children's Privacy

HIKI Rescue does not operate a personal-data collection service and does not knowingly collect personal information from children or adults.

## 7. Changes to This Policy

This privacy policy may be updated if HIKI Rescue's functionality, distribution method, or data-handling behavior changes.

The latest version will be published in the official HIKI Rescue GitHub repository.

## 8. Contact

For privacy or support inquiries:

**Eltax Support**  
**eltax.support@gmail.com**

Official project repository:  
https://github.com/laikal/HIKI-Rescue/

# HIKI Rescue 개인정보 처리방침

**최종 수정일: 2026년 9월 21일**

HIKI Rescue는 **Eltax**가 개발한 Windows 복구 및 점검 유틸리티입니다.

## 1. 개인정보

HIKI Rescue는 개인정보를 수집하거나 외부 서버에 저장하지 않으며, 판매하거나 제3자와 공유하지 않습니다.

HIKI Rescue는 다음 기능을 사용하지 않습니다.

- 텔레메트리
- 사용 분석
- 광고
- 추적 기술
- 사용자 계정
- HIKI Rescue가 운영하는 클라우드 저장소
- HIKI Rescue가 운영하는 원격 서버

## 2. 로컬 처리

HIKI Rescue의 복구, 진단, 유지보수 및 시스템 점검 기능은 사용자의 Windows 장치에서 로컬로 실행됩니다.

사용자가 선택한 기능에 따라 다음과 같은 Windows 기본 기능, 유틸리티 또는 API를 실행할 수 있습니다.

- 시스템 복원
- DISM
- 시스템 파일 검사기(SFC)
- CHKDSK
- Windows 디스크 정리
- Windows 메모리 진단
- 안정성 모니터
- 시스템 정보
- DNS 캐시 초기화
- 디스플레이 구성 캐시 초기화

이러한 작업은 사용자의 장치에서 로컬로 시작되고 처리됩니다.

## 3. 로컬 로그 및 백업

HIKI Rescue는 복구 또는 진단 작업에 필요한 경우 로컬 진단 로그 또는 백업 파일을 생성할 수 있습니다.

예를 들어, 지원되는 디스플레이 구성 캐시 항목을 변경하기 전에 레지스트리 백업 파일을 생성할 수 있습니다.

이러한 파일은 사용자의 장치에 남으며, HIKI Rescue 또는 Eltax가 운영하는 외부 서버로 자동 전송되지 않습니다.

저장 위치는 설치 방식 및 Windows 패키징 환경에 따라 달라질 수 있습니다.

## 4. 외부 링크

HIKI Rescue는 사용자가 해당 버튼이나 링크를 명시적으로 선택한 경우에만 외부 웹사이트를 열 수 있습니다.

예시는 다음과 같습니다.

- HIKI Rescue 공식 GitHub 저장소
- Hikimori Neko CHZZK 채널

HIKI Rescue는 이러한 웹사이트로 개인정보를 자동 전송하지 않습니다.

외부 웹사이트를 연 이후의 이용에는 해당 웹사이트의 개인정보 처리방침과 이용 약관이 적용됩니다.

## 5. Microsoft Windows 구성요소 및 서비스

HIKI Rescue의 일부 기능은 Microsoft Windows가 제공하는 유틸리티, API 및 구성요소를 사용합니다.

Windows 또는 Microsoft 서비스가 직접 처리하는 정보에는 Microsoft의 관련 개인정보 보호정책 및 약관이 적용되며, 이는 HIKI Rescue의 통제 범위 밖에 있습니다.

## 6. 아동의 개인정보

HIKI Rescue는 개인정보 수집 서비스를 운영하지 않으며, 아동 또는 성인의 개인정보를 의도적으로 수집하지 않습니다.

## 7. 개인정보 처리방침 변경

HIKI Rescue의 기능, 배포 방식 또는 데이터 처리 방식이 변경되는 경우 이 개인정보 처리방침도 변경될 수 있습니다.

최신 버전은 HIKI Rescue 공식 GitHub 저장소에 게시됩니다.
